    Resizing Components

    Introduction#

    Nexus chart and time bar components adapt to fit the size of their parent element in the DOM. Any changes in the size of the parent will be adopted by the chart or time bar, making it easy to manipulate their size and shape.

    The Nexus container#

    The GraphNexus.create() function creates a container that the chart sits inside. So when you create a chart or time bar, that element will be a child of the specified container.

    var chart;
GraphNexus.create({ container: 'kl-chart' }, function (err, result) {
  chart = result;
  // Load your chart here!
});

    Your html element structure should then look something like this:

    <div id='kl-chart' style='width:600px; height:500px;'>
  <canvas height="500" width="600" id="GraphNexus-chart-1" style="-ms-touch-action: none; touch-action: none; outline: none;" tabindex="8888"></canvas>
</div>

    Note that a Nexus component will not render to a container if the container's css style property has display: none, width = 0 or height = 0.

    Styling and CSS#

    As the chart resizes automatically you should make sure you target your CSS at the container, and not the Nexus element itself.

    As Nexus elements adapt to fill the size of their parent, we advise using box-sizing to make sizing the chart simpler:

    * {
  box-sizing: border-box;
}

    Nexus elements adapt to fit the size of their parent, so you should be aware of other rules in css modules that may interfere with this. Modules such as css grid - where parent elements are sized based on their children - can cause unexpected behaviour.

    Fullscreen mode#

    When you want to put the chart in fullscreen mode, you can use the hierarchy rules of css to control the size of the chart:

    HTML
    <div id='kl-main' style="width: 800px; height: 600px;">
  <div id='fullScreen'>
    <div id='kl-chart'>
      <canvas id="GraphNexus-chart-1"></canvas>
    </div>
  </div>
  <button id='fullscreenBtn'>Fullscreen</button>
</div>
    JavaScript
    // When the window is loaded
$(window).on('load', function() {

  var chart;

  // Create Nexus chart as a child of the DOM element with id 'kl-chart'
  GraphNexus.create({ container: 'kl-chart', options:{backColour: 'white' } }, function (err, result) {
    chart = result;
    // Load your chart here!
  });

  // Toggle fullscreen mode when the button is clicked
  $('#fullscreenBtn').click(function(evt) {
    if(GraphNexus.fullScreenCapable()) {
      GraphNexus.toggleFullScreen(document.getElementById('fullScreen'));
    }
  });
});

    You can then set the styling for all child elements to inherit from the kl-main div, or select only the fullscreen div to make the chart fill the screen.

    Resizing in older Nexus versions#

    In versions of Nexus before the 5.3 release, the chart element won't automatically resize to fit its parent. We recommend updating to use the new method of creating components, but if you are unable to, then you will need to use the setSize API every time you want to change the size of the Nexus element.

    When you create a Nexus component using GraphNexus.create without setting the container parameter, it uses the specified DOM element's clientWidth and clientHeight to set the size for the chart. Even if you intend to resize later it's useful to have a default height and width set in the DOM. We recommend not using percentage values. For example:

    HTML
    <div id='kl' style='width:600px; height:500px;'></div>
    JavaScript
    var chart;
GraphNexus.create('kl', function (err, result) {
  chart = result;
  // Load your chart here!
});

    The resulting canvas element will look as follows:

    <canvas height="500" width="600" id="kl" style="-ms-touch-action: none;touch-action: none; outline: none;" tabindex="8888"></canvas>

    You can also pass a DOM element to GraphNexus.create and Nexus will generate an id for the element

    var chart;
var el = document.createElement('div');
document.body.append(el);
GraphNexus.create(el, function (err, result) {
  chart = result;
  // Load your chart here!
});

    The resulting canvas element will look as follows:

    <canvas height="500" width="600" id="GraphNexus-chart-1" style="-ms-touch-action: none; touch-action: none; outline: none;" tabindex="8888"></canvas>

    After the component has been created, any further changes to the size of the component should be made using GraphNexus.setSize.

    Using setSize#

    If you haven't set the container, Nexus components have to do internal calculations when they're created or resized to avoid issues with scaling and the localisation of chart events.

    This means that any changes to the component's size using libraries or CSS will distort the chart and cause issues with user interaction. To prevent this use GraphNexus.setSize every time the component size needs to change to update the size of the component.

    Examples#

    In all these examples, we've used jQuery to make the code easier to read. You can use any libraries you wish.

    Browser resize#

    Handling browser resize is pretty straightforward. The window object has an event called onresize which is invoked every time the browser window changes size. In modern browsers it is also invoked when the browser's zoom level is changed.

    In this example, a chart is created, and then sized to be 50% of the window size. Then, if the browser is resized, this ratio is maintained. You can use any calculation you wish.

    HTML
    <body>
  <!-- provide element for the chart with a default height and width -->
  <div id='kl' style="width:800px;height:600px;"></div>
</body>
    JavaScript
    // When the window is loaded
$(window).on('load', function() {
  var chart;

  // Function to calculate and set the new size
  function resize() {
    var doc = $(document);
    GraphNexus.setSize('kl', doc.width() * 0.5, doc.height() * 0.5);
    // After resize, fit the chart to the window
    chart.zoom('fit');
  }

  // Create Nexus chart in DOM element with id 'kl'
  GraphNexus.create('kl', function (err, result) {
    chart = result;
    // Load your chart here!

    // Call resize to get desired chart size
    resize();
  });

  // Add handler for window resize event
  $(window).on('resize', resize);
});

    GraphNexus.setSize can also be passed a DOM element.

    // Function to calculate and set the new size
  function resize() {
    var doc = $(document);
    var klElement = document.getElementById('kl');
    GraphNexus.setSize(klElement, doc.width() * 0.5, doc.height() * 0.5);
    // After resize, fit the chart to the window
    chart.zoom('fit');
  }

    Using fullScreen mode#

    This example shows you how to resize when using the GraphNexus.toggleFullScreen function. Typically, you would use a parent element to go full screen, and then resize other elements, including the chart, accordingly.

    HTML
    <body>
  <div id='fullScreen'>
    <div id='kl' style="width: 800px; height: 600px;"></div>
  </div>
  <button id='fsBtn'>Fullscreen</button>
</body>
    JavaScript
    // When the window is loaded
$(window).on('load', function() {

  var chart;

  // Function to set the size on enter and exit of fullscreen
  function resize(isFullScreen) {
    if(isFullScreen) {
      GraphNexus.setSize('kl', screen.width, screen.height);
      // Hide the button in fullscreen mode
      $('#fsBtn').hide();
    } else {
      GraphNexus.setSize('kl', 800, 600);
      $('#fsBtn').show();
    }
    // After resize, fit the chart to the window
    chart.zoom('fit');
  }

  // Create Nexus chart in DOM element with id 'kl'
  GraphNexus.create({id: 'kl', options:{backColour: 'white'}}, function (err, result) {
    chart = result;
    // Load your chart here!
  });

  // Toggle fullscreen mode when the button is clicked
  $('#fsBtn').click(function(evt) {
    if(GraphNexus.fullScreenCapable()) {
      GraphNexus.toggleFullScreen(document.getElementById('fullScreen'), resize);
    }
  });
});
