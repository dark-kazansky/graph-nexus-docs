    Using Nexus with plain JavaScript

    Introduction#

    This quick start guide shows how to integrate a simple Nexus visualisation into an app. When you are finished, you will have a simple interactive Nexus chart.

    Note that if you store Nexus in your source control you must ensure it's not publicly available. Read more about the Obfuscation Requirements before deploying your application.

    Step 1: Create a new web page#

    Create a new directory named my-app and create a new npm package from this directory:

    mkdir my-app && cd my-app
npm init -y

    Download the Nexus package from the link below and place it in the my-app directory.

    Download Nexus 7.5.0-6286156683

    In the terminal from the my-app directory, add Nexus as a package dependency:

    npm add file:./graph-nexus-1.0.0.tgz
    Nexus also includes extra dependencies for map mode and PDF export. See their respective documentation for more information on how to use them.

    Next, add a file my-app/index.html with the following contents:

    <!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div id="kl" style="width: 100vw; height: 100vh;" ></div>
  </body>
</html>

    This HTML defines a div where the Nexus chart will later appear.

    Step 2: Run a web server#

    You can simply open index.html in a browser directly from the file system, but Nexus needs to run via a web server to display images correctly.

    You can use any web server you like, but live-server is a simple option which will automatically reload the page when you make changes.

    To use live-server, you should have the latest version of Node.js installed. To check your version, you can run node -v in the console.

    Then run in the my-app directory:

    npx live-server

    At this stage you will see a blank page.

    Step 3: Create a chart#

    Add a new script tag to index.html just after the <meta> tag:

    <script src="./app.js" type="module"></script>

    and create a new file my-app/app.js with the following contents:

    import GraphNexus from './node_modules/nexusgraph/esm/index.js'

const chartDivId = 'kl';
let chart;

const data = {
  type: 'LinkChart',
  items: [{ id:'id1', type: 'node', c: '#43976C', x:150, y: 150, t:'Hello World' }]
};

GraphNexus.paths({ images: './node_modules/graph-nexus/assets/' });
GraphNexus.create({container: chartDivId}).then((loadedChart) => {
  chart = loadedChart;
  chart.load(data);
});

    This application loads Nexus as an ESM module. Nexus is also available as a UMD module which declares Nexus as a global variable.

    The data object describes a Nexus chart with a single node with the label text "Hello World". We'll replace this later with a more complex chart.

    When the page loads, we call GraphNexus.create() to create a Nexus chart in the kl div, and then load the chart data.

    You should now see a simple Nexus chart in your browser:

    The navigation controls can be used to pan and zoom around the chart. Clicking the icon at the bottom right displays an overview of the chart.

    GraphNexus.create({container: chartDivId}).then((loadedChart) => {

});

    This performs an organic layout, but there are lots of other layouts to try - have a look at the API Reference on layouts for more options.

    Step 5: Add event handling#

    Now that we're displaying the network, let's add some code to respond when the user clicks an item on the chart. We'll start by adding an event handler function to my-app/app.js: 

    function clickHandler({ id }) {
  console.log(`you clicked on ${id}`);
}

    And then attach the click event in the GraphNexus.create() promise once chart is set. 

    chart.on('click', clickHandler);

    Try clicking a few items on the chart. In the developer tools console you'll see that an object containing the id of the clicked chart item is passed to the click handler, or null if you click on the chart background. What happens if you click on the navigation tools?

    Step 6: Update the chart#

    Now let's update the chart when the user clicks on a chart item. Change the clickHandler code to:

    function clickHandler({ id }) {
  if (chart.getItem(id)) {
    const neighbours = chart.graph().neighbours(id).nodes;
    chart.foreground(node => node.id === id || neighbours.includes(node.id));
  } else {
    chart.foreground(node => true);
  }
}

    The new clickHandler function uses chart.getItem() to check whether the clicked id belongs to a node or a link in the chart.

    If it does, then we use chart.graph().neighbours() to find the nodes connected to the clicked item, and then call chart.foreground() to put them in the foreground, and other chart items in the background.

    If the user clicked on something else, such as the chart background, then we foreground all the chart items.
