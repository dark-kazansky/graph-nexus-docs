    Using Nexus with React

    Introduction#

    This quick start adds an interactive Nexus chart to a React app, using the React components shipped in the Nexus package. See the React Reference for every property and event.

    Requirements#

    A current Node.js LTS. Check with node -v.

    Step 1: Create a React app#

    npm create vite@latest my-app -- --template react
cd my-app
npm install

    Step 2: Add Nexus to the app#

    Build the Nexus package from the Nexus repository (or use a tarball you were given):

    npm run build && npm pack      # -> graph-nexus-1.0.0.tgz

    Then, from the my-app directory, install it and copy the bundled icons into the app's public folder:

    npm install file:./graph-nexus-1.0.0.tgz
cp -R ./node_modules/graph-nexus/assets/icons ./public/icons

    Step 3: Create a chart#

    Replace src/App.jsx with:

    import { useRef } from 'react';
import { Chart } from 'graph-nexus/react';
import GraphNexus from 'graph-nexus';
import './App.css';

GraphNexus.paths({ images: '/' }); // icons/ lives in public/

const data = {
  type: 'LinkChart',
  items: [
    { type: 'node', id: 'p1', t: 'Alice', u: 'icons/person.svg' },
    { type: 'node', id: 'p2', t: 'Bob', u: 'icons/person.svg' },
    { type: 'node', id: 'p3', t: 'Carol', u: 'icons/person.svg' },
    { type: 'node', id: 'b1', t: 'Bank', u: 'icons/money.svg' },
    { type: 'node', id: 'c1', t: 'Acme Ltd', u: 'icons/building.svg' },
    { type: 'link', id: 'l1', id1: 'p1', id2: 'b1', a2: true, t: '$1,200' },
    { type: 'link', id: 'l2', id1: 'p2', id2: 'b1', a2: true, t: '$800' },
    { type: 'link', id: 'l3', id1: 'b1', id2: 'c1', a2: true, t: '$2,000' },
    { type: 'link', id: 'l4', id1: 'p3', id2: 'c1' },
    { type: 'link', id: 'l5', id1: 'p1', id2: 'p2' },
  ],
};

export default function App() {
  const chartRef = useRef(null);

  const onReady = chart => {
    chartRef.current = chart;
    chart.layout('organic');
  };

  const onClick = ({ id }) => {
    const chart = chartRef.current;
    if (id && chart.getItem(id)) {
      const neighbours = chart.graph().neighbours(id).nodes;
      chart.foreground(node => node.id === id || neighbours.includes(node.id));
    } else {
      chart.foreground(() => true);
    }
  };

  return <Chart className="chart" data={data} onReady={onReady} on={{ click: onClick }} />;
}

    Give the chart a size in src/App.css. The component fills its parent, so the parent or the className must have a height:

    html, body, #root { margin: 0; height: 100%; }
.chart { width: 100vw; height: 100vh; }

    Run npm run dev. You should see the network laid out, and you can drag, pan and zoom.

    Step 4: Respond to clicks#

    Clicking a node now puts it and its neighbours in the foreground; clicking the background restores every item. chart.getItem() checks the clicked id, chart.graph().neighbours() finds connected nodes and chart.foreground() fades the rest.

    The chart object passed to the ready handler is the full Chart API, so anything in the API reference can be called on it.
