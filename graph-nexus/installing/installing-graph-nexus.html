    Installing Nexus

    Introduction#

    Nexus ships as a single npm package, graph-nexus, with no runtime dependencies. The package contains ES modules, a CommonJS build, a UMD bundle for script tags, TypeScript typings, React / Vue / Angular wrappers and the bundled assets/ (icons, flags, fonts, Leaflet for map mode).

    Step 1: Get the package#

    Nexus is distributed as a tarball, graph-nexus-1.0.0.tgz. Use the tarball supplied by the Nexus team, or build it yourself from the Nexus source repository:

    npm install
npm run build
npm pack
# creates graph-nexus-1.0.0.tgz

    Step 2: Add Nexus to your project#

    Copy the tarball into your project directory, then add it as a dependency:

    npm install file:./graph-nexus-1.0.0.tgz

    This adds an entry like "graph-nexus": "file:graph-nexus-1.0.0.tgz" to your package.json. Commit the tarball (in a private repository) or host it on a private registry so that every developer and CI build installs the same version. See Obfuscation Requirements before making it reachable from a public location.

    Step 3: Import Nexus#

    // ES modules
import GraphNexus from 'graph-nexus';

// CommonJS
const GraphNexus = require('graph-nexus');

    Framework wrappers are exposed as sub-paths: graph-nexus/react, graph-nexus/vue and graph-nexus/angular. See Importing Nexus for details.

    Without a bundler: script tag#

    Copy node_modules/graph-nexus/dist/graph-nexus.umd.js (and the assets/ folder if you use icons, fonts or map mode) to your web server and load it with a script tag. It defines a global GraphNexus:

    <script src="graph-nexus.umd.js"></script>
<script>
  GraphNexus.paths({ assets: '/path/to/assets/' });
  GraphNexus.create('chart').then(function (chart) { /* ... */ });
</script>

    Step 4: Check the installation#

    Add a container with an explicit size and load a two-node chart:

    <div id="chart" style="width: 800px; height: 600px"></div>
    import GraphNexus from 'graph-nexus';

const chart = await GraphNexus.create('chart');
await chart.load({
  type: 'LinkChart',
  items: [
    { type: 'node', id: 'a', t: 'Alice' },
    { type: 'node', id: 'b', t: 'Bob' },
    { type: 'link', id: 'ab', id1: 'a', id2: 'b' },
  ],
});
await chart.layout('organic');

    If you see two connected nodes, Nexus is installed correctly.
