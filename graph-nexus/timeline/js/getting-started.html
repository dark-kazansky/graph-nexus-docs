    Getting Started

    Introduction#

    Nexus Timeline is a JavaScript library for building time-based visualizations.

    This guide introduces some of the basic principles of building a timeline to get you up-and-running with Nexus Timeline. If you are looking for the React version, use the toggle above.

    We are going to embed a simple timeline in an HTML page, before adding data and attaching an event handler.

    Create and Serve an App#

    First we need to set up the file structure inside your project's root folder. You can also use an existing app, but your architecture may require you to make some changes.

    touch package.json index.html index.css index.js
# or index.ts

    Copy the following into package.json. We are going to use Parcel to bundle and serve the app, but you can use an alternative.

    {
  "name": "my-nexus-timelinegraph-project",
  "version": "1.0.0",
  "license": "UNLICENSED",
  "dependencies": {
    "parcel": "2.3.2",
    "@babel/core": "^7.0.0"
  },
  "scripts": {
    "start": "parcel index.html -p 1234"
  }
}

    Then install the dependencies and start the server:

    yarn install && yarn start

    Or if you're using npm:

    npm install && npm run start

    Some browsers cache aggressively, so during development you may need to manually refresh.

    If you are using TypeScript, then you can include your index.ts file in your index.html page and Parcel will automatically transpile it for you.

    Installing#

    Install Graph Nexus from your package registry or from a packed tarball built with npm run build && npm pack:

    # npm
npm install graph-nexus

# yarn
yarn add graph-nexus

    Creating a Timeline#

    It's time to add a timeline to the app.

    First we need to add an element to the HTML page so that Nexus Timeline can attach a Timeline to it. We then call createTimeline(), passing the id of the parent element to it.

    Let's load the files into the page and create a div for the Timeline. Add the following to index.html:

    <!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Hello, world!</title>
    <link rel="stylesheet" href="index.css" />
    <script type="module" src="index.js"></script>
  </head>
  <body>
    <div id="my-timeline" class="timeline"></div>
  </body>
</html>

    Next we import createTimeline into the page, create a Timeline element in index.js, and add some data:

    // index.js
import { createTimeline } from 'graph-nexus';

const timeline = createTimeline('my-timeline');

const data = {
  entities: { 'Person 1': {}, 'Person 2': {} },
  events: {
    'Phone call 1': {
      entityIds: ['Person 1', 'Person 2'],
      time: new Date(2020, 6, 1, 12, 0),
    },
    'Phone call 2': {
      entityIds: ['Person 1', 'Person 2'],
      time: new Date(2020, 6, 1, 13, 0),
    },
  },
};

timeline.set(data);
timeline.fit();

    And define some styling in index.css:

    /* index.css */
.timeline {
  height: 100vh;
}

body {
  margin: 0;
}

    The timeline sets its height and width to equal the size of its parent element, so any styles should be set on the parent.

    Handling Interactions#

    Nexus Timeline has a few useful default functions to let users navigate the timeline. You can add your own custom behavior to user interactions by attaching a custom handler:

    // index.js
function clickHandler(event) {
  window.alert(`You clicked a timeline item of type '${event.targetType}'`);
}

    And then attach it to the Timeline by adding this after createTimeline():

    // index.js
timeline.on('click', clickHandler);

    Congratulations! You have created your first Nexus Timeline app. Here are some ideas what to do next:

    • Check out more of Nexus Timeline's features in our Storybook.
    • Find details on methods and data formats in our API Reference.
    • Try out our live code Playground.
