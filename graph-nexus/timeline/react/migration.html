    Migration

    Nexus Timeline 2.0 changes the way data is displayed and how users interact with it. This guide gives an overview of these changes to help you upgrade and make the most of the new features.

    The key changes are:

    • Nexus Timeline uses a new lens to visualize and examine large datasets.
    • The concept of closed groups and any related API are removed.

    You should be able to load your data into Nexus Timeline 2.0 without issues. However, your data may look very different, especially if you have more entities than can fit on the screen at one time. You may want to think about how to communicate this to your end users.

    Introducing lens#

    In earlier versions, when the timeline contained more entities than could fit on the screen, Nexus Timeline collapsed entities into 'runs', or, if you've defined types or groups in your data, 'closed groups'. Both were opened using the expand control.

    Nexus Timeline 2.0 draws all entities and their events, even if there isn't enough space to display each entity label. If there are too many rows to label, instead of groups users can now open and close the lens.

    Removed APIs#

    All APIs referencing open and closed groups have been removed. If you have any code which references them, you'll need to remove or modify it:

    • expand event
    • expandedRowId
    • expand option of controls
    • targetType values: 'collapse', 'expand', 'entityGroupMore', 'entityGroupRun'

    In addition, the priority option of entityType remains in the API for file format compatibility but it doesn't have any effect.

    For the full set of default-setting changes and other API changes, see the plain JavaScript Migration Guide — every change applies identically to the React component.
