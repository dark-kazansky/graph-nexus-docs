    API Signatures

    Every public method and property, with its TypeScript signature from graph-nexus.d.ts (shipped in the package). Option and item shapes are in the typings and on the API Index.

    Methods that return a Promise also accept a trailing callback, for example chart.layout('organic', {}, () => {}).

    GraphNexus#

    The GraphNexus object: creates components and holds global settings.

    GraphNexus.create#

create(defs: ComponentDefinition[]): Promise<(Chart | TimeBar | Timeline)[]>
create(def: ComponentDefinition): Promise<Chart | TimeBar | Timeline>
