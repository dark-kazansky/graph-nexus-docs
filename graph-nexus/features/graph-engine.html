    Graph Engine

    Introduction#

    The graph engine powers the analysis features in Nexus. It keeps these features separate from the methods used to render charts. This means you can run graph traversals and Social Network Analysis computation without having to display every chart item first.

    Graph Engine Advantages#

    There are many advantages to using the graph engine, particularly when working with large datasets:

    • You can carry out analysis on a subset of the rendered graph.
    • It's quicker and easier to carry out graph traversals such as shortestPath, and social network analysis metrics, including degrees or betweenness.
    • It's integrated into Nexus already, so there's no need to add extra files.
    • You don't have to manipulate the chart to run graph analysis.

    Getting started#

    In these code samples, the Graph Engine performs computation tasks without rendering the chart.

    Step 1 - Create a Graph Engine instance:

    const graph = GraphNexus.getGraphEngine();

    Step 2 - Use the Nexus Graph Engine API to load the data:

    const data = { type: 'LinkChart', items:  [ ... ] };
graph.load(data);

    You can also load a saved chart (or serialize the current one) in the Graph Engine instance:

    graph.load(chart.serialize());

    Step 3 - Perform the graph traversals or SNA computations:

    const degrees = graph.degrees();

    Graph Engines in NodeJS#

    You can use the graph engine in any javascript environment, including NodeJS.

    Here are some useful code-snippets to set up the Nexus Graph Engine in NodeJS.

    Step 1 - Import graph-nexus:

    import GraphNexus from 'graph-nexus';

    Step 2 - Create a Graph Engine instance:

    const graph = GraphNexus.getGraphEngine();

    Step 3 - Use the Nexus Graph Engine API to load data:

    const data = {type: 'LinkChart', items:  [ ... ]};
graph.load(data);

    or load a saved chart in the Graph Engine instance:

    graph.load(savedChart);

    Step 4 - Perform the graph traversals or SNA computations:

    const degrees = graph.degrees();

    See Also#

    Centrality Measures#

    The Nexus graph engine comes with many centrality measures that can be used for social network analysis. See the Graph Centrality documentation for details on how and when to use them.

    Graph Engine API#

    A Graph Engine instance offers every function available in the chart.graph(), plus methods to load and manipulate the data.

    If a method in the API Reference is labelled graph engine only it's only available in the Graph Engine.

    For more information, see the API Reference.

    Best practice#

    The graph engine is not a graph database. It's designed to perform graph traversals and run efficiently in a web browser. It isn't meant to hold billions of nodes and edges in a back-end environment.
