    React Reference

    New to Nexus with React? Start with the React tutorial.

    Components#

    import { Chart, TimeBar } from 'graph-nexus/react';  // default export: Chart

    Both are function components built on hooks. They need React 17 or later (an optional peer dependency of graph-nexus). Each renders a div that fills its parent (width and height 100%) and creates the Nexus component inside it on mount; it is destroyed on unmount.

    <Chart
  data={data}
  options={options}
  on={{ click: handler, "selection-change": handler2 }}
  onReady={chart => {}}
  className="chart"
  style={{ height: 600 }}
/>

    Props#

    PropTypeDescription
    dataobjectData in Nexus format, loaded on creation and reloaded with load() whenever the object reference changes.
    optionsobjectPassed to GraphNexus.create() and re-applied with options() whenever the reference changes.
    onobjectEvent name to handler, for example { click: e => {} }. Every chart or time bar event is supported; the latest object is used on each event, so inline handlers are fine.
    onReadyfunctionCalled once with the Nexus chart or time bar after the initial data has loaded. Keep a reference to call the API.
    classNamestringClass for the container div.
    styleobjectInline style merged over { width: '100%', height: '100%' }.

    The components do not lay out data automatically; call chart.layout() in onReady, or supply positions in the data.

    Calling the API#

    const chartRef = useRef(null);
<Chart data={data} onReady={chart => { chartRef.current = chart; }} />
// later
chartRef.current.zoom('fit');

    For events and methods see Chart Events, Time Bar Events and the API Reference.
