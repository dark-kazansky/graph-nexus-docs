About aggregate links

A chart with many links between the same nodes or combos gets cluttered. The aggregateLinks chart option draws each group of links that share properties as one aggregate link.

Set aggregateBy to merge only links that share a custom d property, here the transport, and aggregateByDirection to split them by direction.

A link-aggregation event fires each time an aggregate link is created, updated or deleted, so you can style it. Here each one gets a width and a counter glyph for its child count.

Aggregate links work well with nested combos: closed combos still show which groups are connected, and opening one reveals the links inside.
