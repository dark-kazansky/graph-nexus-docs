Aggregating Links

Switch between link aggregation options and double-click combos to open and close them, showing different levels of detail.

Link aggregation

Why Aggregated Links?

A chart with many links between individual pairs of nodes or combos becomes cluttered and hard to read. The aggregateLinks chart option draws each group of links that share properties as one aggregate link.

Besides aggregating every link between a pair of nodes, set aggregateBy to aggregate only links that share a custom d property, and aggregateByDirection to split them by direction.

A link-aggregation event fires each time an aggregate link is created, updated or deleted, so you can style it, here with a width and a counter glyph for its child count.

Aggregate links and combos

Aggregate links are especially useful with nested combos, which can reveal many underlying links when opened. For closed combos they organise links at any nesting level while still showing which combos are connected.

Key APIs: chart option aggregateLinks, chart.on('link-aggregation').
