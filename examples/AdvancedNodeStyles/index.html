The right node design can help you visualise any type or amount of data in an intuitive way, give chart users the best experience and fit your charts into any application.

Custom shaped nodes

Set the width (w) and height (h) of nodes to create rectangular nodes, and round one or more corners with borderRadius. For any other shape, overlap font icons added as labels in the t array.

Multiple styled labels

The t array of objects adds multiple text and font icon labels. Each label has its own styling and position, and can carry information or act as decoration.

Custom label interactions

Labels can serve as buttons, icons or toggles: pointer events report the label under the pointer in subItem. Labels with changing styles make progress bars or stacked bars.

Images inside labels

To put images on nodes with multiple styled labels, add them as glyphs on the node.

Key functions: chart.foreground, chart.getItem, chart.on, chart.setProperties.
