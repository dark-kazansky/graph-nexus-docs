About node styles

The right node design shows any type or amount of data clearly and fits your charts into any application.

Custom shaped nodes: set the width (w) and height (h) for rectangles, and round one or more corners with borderRadius. For other shapes, overlap font icons added as labels in the t array.

Multiple styled labels: the t array adds several text and font icon labels, each with its own style and position.

Label interactions: labels can act as buttons, icons or toggles. Pointer events report the label under the pointer in subItem, and labels with changing styles make progress or stacked bars.

Images: to put images on nodes with styled labels, add them as glyphs.

Key functions: chart.foreground, chart.getItem, chart.on, chart.setProperties.
